# TrainSphere — Corporate Training & Workshops Task Manager

Single-page **TrainSphere** (Corporate Training & Workshops) Kanban workflow task manager featuring full CRUD array operations (`Create`, `Read`, `Update`, `Delete`), live search, and status filtering across **Pending**, **In Progress**, and **Completed** columns, ready for GitHub and Vercel.

## Files Included
- `index.html` — Root entry point for GitHub Pages and Vercel
- `trainsphere-workshop-task-manager.css` — External stylesheet for sidebar navigation, Kanban board columns, color-coded task cards, and responsive layout
- `trainsphere-workshop-task-manager.js` — CRUD task array management, search filtering, status transitions, and DOM rendering
- `vercel.json` — Vercel static hosting configuration
